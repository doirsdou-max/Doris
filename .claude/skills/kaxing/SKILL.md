# 卡型分析（季度客单价 / 扩科率同比）

目标：回答"今年X季度 vs 去年同季度，客单价、扩科率怎么变、为什么变"，输出给昊哥的微信文案 + 一张三年级卡型结构图。

**先读 `references/pitfalls.md`**——每一条都是真实踩过的坑。

## 一、输入

| 材料 | 用途 | 必需 |
|---|---|---|
| 两年订单明细Excel（sheet「1-汇总-组会-amount总退费人科数年级按原始课程id」） | 全部计算 | ✅ |
| 看板当期数据截图（区域数据：出单人数/营收/客单价1/学科拓科率，按年级） | 总数核对、标题口径 | ✅ |
| 石墨价格表（【通用系列】价格快速定位 / 拉新端组合售卖产品 / 20XXH2通用系列） | 成交价核对 | ✅ |
| 产品上架表（明哲团队：卡型/产品/包装名称/两年开售停售日期） | 判断供给侧还是销售侧 | 建议 |

取数要求见 `references/data-request.md`，发给数仓前先对一遍。

## 二、口径（固定，不要每次重新讨论）

1. **时间**：只统计当期转化课（本季度开课期次）的学员，且订单业绩归属时间在本季度内。两年必须同一取数条件。
2. **年级**：用"转化课实际年级"＝该原始课程id下学员所购正价课的多数年级。原始年级字段不可信（去年曾把新高三标成高二）；全国包=新高一，初三转化课学员按实际购买年级归类。只看高一/高二/高三。
3. **学科人次**：按「学员×科目」去重；只统计有付费（营收>0）的科目；赠科不算学科。
4. **价格**：每科净价 =（营收−总退费）÷学科人次；客单价 = 净营收÷人头；扩科率 = 学科人次÷人头。
5. **卡型**：按「卡组合」字段整体归类，不按子卡拆；同一学员同一科目有多种卡时，按净营收最高的卡归类。注意同名"全体系直通卡"是两个产品（见 `references/card-mapping.md`）。
6. **不含通用渠道**（百度/小红书）；文案里注明看板总计口径不同。

## 三、流程

1. **读数据 + 核对**（任何一项不过，停下来问Doris，不要自行假设）：
   - 订单号范围是否集中在本季度（跨度异常=混入季度外订单）；抽1-2个可疑订单号请Doris后台查业绩归属时间。
   - 原始课程id是否有季度前的回捞课程（设 `--min-cid` 过滤）。
   - 年级推断一致率（今年应≥99%；去年偏低说明标注口径变了）。
   - 各年级人头 vs 看板（偏差≤5%）。
   - 各卡型成交价中位数 vs 价格表（按单科/两科/三科及以上档位，未扣退费比较）；偏差大先查营收分摊（如决胜卡赠科分摊）。
2. **运行脚本**：
   ```bash
   python3 scripts/kaxing.py --last 去年.xlsx --this 今年.xlsx --min-cid-last 255400 --min-cid-this 287200 \
       --label-last 25年Q3 --label-this 26年Q3 --gift-addback 2025H2 --out 输出目录
   ```
   输出：分年级KPI、卡型结构拆解（结构效应/同卡价格效应）、报科数分布、卡型结构图PNG。
3. **归因**：客单价 = 扩科率 × 每科均价；每科均价变化 = 卡型结构效应 + 同卡价格效应。对照产品上架表区分：
   - 售卖时间两年相同但占比变 → **销售侧**（写进"原因"）
   - 上架时间/产品本身变了 → **供给侧**（没定量验证的只写进"另外观察"，不写进原因）
4. **输出**：按 `references/output-template.md` 写微信文案，附图。先给Doris看，确认后再定稿。

## 四、原则

- 不确定的口径、看不清的数字，先问，不脑补。
- 推断（如订单号代表时间、产品排期分流）必须明说是推断，并给出验证方法。
- 文案用"用户"不用"学员"；产品用价格表上的正式名称。
- 红=达标、绿=不达标（Doris约定），图里不要用红色表示"下降"。
