# 取数要求（发给数仓）

报表：「1-汇总-组会-amount总退费人科数年级按原始课程id」

**字段**：原始课程id、orderid、转化科目、转化年级、基地、付费用户id、原始年级、卡组合、售卖/包装名称、营收、总退费、人科数+年级；**请加：业绩归属时间（或支付时间）**。

**筛选条件（两年必须一致）**：
1. 业绩归属时间：本季度起止（如 2025-07-01 ~ 2025-09-30）
2. 原始课程：本季度开课的转化课期次（不含回捞/季度前期次）
3. 年级：包含全国包（新高一）、初三转化课

**拿到后自查**：
- 订单号是否集中在一个区间（出现大断层=混入季度外订单）
- 抽1个最大订单号，后台查业绩归属时间是否在本季度
